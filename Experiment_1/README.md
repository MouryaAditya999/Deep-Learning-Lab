# Experiment 1 – Single Layer Perceptron for Binary Classification

## Objective

Implement a Single Layer Perceptron from scratch for binary classification using the Banknote Authentication Dataset. The experiment demonstrates the perceptron learning algorithm, model training, evaluation, and visualization of the learning process.

## Dataset

- **Dataset:** Banknote Authentication Dataset
- **Source:** UCI Machine Learning Repository
- **Samples:** 1372
- **Features:** 4
- **Classes:** 2 (Authentic / Forged)

## Features

- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Single Layer Perceptron implemented from scratch
- Step Activation Function
- Training using Perceptron Learning Rule
- Model Evaluation
- Confusion Matrix
- Learning Rate Comparison
- Logic Gate Implementation (AND, OR and NOT)
